Guide

What's in this app, and how to use it.

Today

A single overview pulling from every other tab — today's timetable, recent notes, recent log entries, your tables, active to-dos, and active work items. Click anything here to open it in full.

Timetable

Plan slots per day of the week. Click a slot to edit its time, subject, topic, or even move it to a different day.

Notes & Learning log

Both have a small formatting toolbar: bold, headings, text alignment, and four highlight colors. Click any note or log entry to expand it and edit or delete it.

Tables

Build your own tracker with custom columns and rows — anything spreadsheet-like.

To-do

Simple tasks with a due date. Every completed task is worth 10 points, shown as total / weekly / monthly score, plus bar charts of completions.

Progress

For bigger pieces of work. Each item can be Pending, Semi-done, or Done. Marking something Semi-done opens a small note box to record what's left — edit it any time. Marking Done automatically moves it to the Done list. Daily / Weekly / Monthly / Custom views show how much you finished, with a bar chart.

Backup & sync

Data saves to this browser automatically. You can also download a JSON backup, turn on Private mode for a shared computer (nothing gets saved to that device), or connect Google Drive for a private cloud copy.

Login lock

A simple username/password screen guards the app. It's a convenience lock for a personal device, not real security — the credentials are visible in the page's own source code.

Today

Ye ek jagah hai jahan baki sab tabs ka khulasa nazar aata hai — aaj ka timetable, recent notes, recent log entries, tumhari tables, active to-dos, aur active work items. Kisi bhi cheez pe click karke usay pura khol sakte ho.

Timetable

Har din ke liye time slots banao. Kisi slot pe click karke uska time, subject, topic badal sakte ho, ya usay kisi aur din pe move kar sakte ho.

Notes aur Learning log

Dono me ek chhota formatting toolbar hai: bold, headings, text alignment, aur 4 highlight colors. Kisi bhi note ya log entry pe click karke usay poora khol ke edit ya delete kar sakte ho.

Tables

Apni marzi ki table banao — jitne chaho columns aur rows, jaise koi bhi spreadsheet.

To-do

Chhote tasks, due date ke saath. Har complete task ke 10 points milte hain — total / weekly / monthly score dikhta hai, saath me bar charts bhi.

Progress

Bade kaam ke liye. Har item Pending, Semi-done, ya Done ho sakta hai. Semi-done select karte hi ek chhota note box khulta hai jahan likh sakte ho ke kya baaki hai — usay kabhi bhi edit kar sakte ho. Done karte hi wo apne aap Done list me chala jata hai. Daily / Weekly / Monthly / Custom views me dekh sakte ho kitna kaam hua, bar chart ke saath.

Backup aur sync

Data khud-ba-khud is browser me save hota hai. Chaho to JSON backup download kar sakte ho, kisi shared computer pe Private mode on kar sakte ho (us device pe kuch save nahi hoga), ya Google Drive connect karke ek private cloud copy rakh sakte ho.

Login lock

Ek simple username/password screen app ko guard karta hai. Ye sirf apne personal device ke liye ek halka lock hai, real security nahi — password page ke apne source code me nazar aata hai.

Backup & sync

Your data lives in this browser by default. Back it up so a cleared cache never costs you your notes.

Local file backup

Works with no setup — downloads/loads a single JSON file.

Private mode — for shared or restricted PCs

When on, nothing is written to this browser. Everything lives only in this tab's memory and disappears the moment you close it — connect Drive (if login is allowed on this PC) to save your work there instead.

Off — saving normally to this browser

Google Drive

Not connected

Reset

Erases everything stored in this browser. Back up first.
